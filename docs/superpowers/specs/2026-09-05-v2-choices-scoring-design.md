# Bizlaw2-seisen2026 v2 設計スペック(選択肢・成績機能)

## 背景

v1(章選択・フリップカード・進捗localStorage・PWA)の実装後、ユーザーが元データ(`ビジ法２精選/01.txt`〜`16.txt`)を大幅に修正し、以下の機能追加を要望した:

1. 表示形式の完全統一(正解選択肢だけ太字になっている問題がある)
2. カード表裏の先頭に「章・章タイトル・問題数」「第N問 タイトル」を表示
3. 出典はカード最下部に移動
4. 選択肢を選択・トグル解除できるようにする
5. 回答解説の選択肢間に空白行、判定文言(「適切である」等)を太字統一
6. できた/苦手ボタンをトグル解除可能に
7. セッション成績(連続正誤)機能+「成績を見る」ボタン
8. カードごとの実施回数★カウンター(0〜10、専用リセットボタン)
9. 難易度情報は扱わない(削除)

## データ調査で判明した事実

ユーザーによる元データ修正後、全16章・172問を再検証した:

- **タイトル**: 全172問に、直前の見出し的な1行(`### タイトル`, `## タイトル`, `**タイトル`など書式は章によりバラバラ)としてタイトルが付与されていることを確認。書式に依存せず「次の問題見出しの直前にある、空行・区切り線以外の最後の1行」を機械的にタイトルとして抽出する方式で全問カバーできる(フォールバック=前問のタイトル、は現データでは事実上発動しない安全網)。
- **難易度**: 元は9章にあったが、ユーザーが削除済み。全ファイルに存在しない。→ 実装しない。
- **選択肢**: ほとんどの問題は①〜⑤(まれに⑥まで)の丸数字1行1選択肢。太字で正解だけ強調されている問題が01・02・05・06・07・08・09・10・12・13・14・15章に多数ある(問題文表示時は太字を除去して統一する)。
- **例外(選択肢を独立行として抽出できない問題、計7問程度)**:
  - **下線部問題(`<u>`タグ使用、01・04・09・13・15章に各1問)**: 選択肢が文章中の下線部として埋め込まれている。→ 下線部自体をタップ選択可能にする。
  - **末尾に注記がある問題(2章第10問)**: 選択肢後に「※…」という注記が1行ある。
  - **選択肢が2行にまたがる問題(12章第15問)**: 「①甲「…」／乙「…」」のように改行を含む。
  - これら注記・複数行のケースは、選択肢抽出ロジックを複雑にするコストに見合わないため、**選択肢抽出に失敗した場合は自動的に「地の文表示(選択不可)」にフォールバックする**。フォールバックしたカードは実装時にレポートする。

## データモデル変更(`cards.js`)

各カードに以下のフィールドを追加/変更する:

```
{
  id, chapter, chapterTitle, chapterCount,   // chapterCount: その章の問題数(ヘッダー表示用)
  questionNumber,                             // 資料上の「第N問」の数値
  title,                                      // 抽出したタイトル文字列
  examRef,
  isProse,                                    // true: 選択肢を独立抽出できず地の文表示(下線部問題・例外含む)
  prompt,                                     // 選択肢を除いた問題文(isProse時は問題文全体)
  choices,                                    // 選択肢の配列(各要素は丸数字込みの表示用テキスト、太字除去済み)。isProse時は空配列
  answerIndex,                                // 正解choicesのインデックス(0始まり)。判定できない場合はnull
  answer,                                     // 元の正解表示文字列(「正解：」の後に表示する用、従来通り)
  explanation
}
```

`chapter`/`chapterTitle`/`chapterCount` は既存の`CHAPTERS`テーブル(ハードコード済み)から採る。難易度フィールドは追加しない。

## 表示設計

**カード共通ヘッダー(表裏とも先頭)**
```
第2章 企業財産の管理と法務（18問）
第1問　預金取引
```

**問題(表)カード**
- ヘッダーの下に`prompt`を整形表示
- `choices`がある場合、各選択肢を同一書式(太字なし)のタップ可能な要素として縦に並べる。タップで反転(選択)、再タップで解除。複数選択肢を同時に選択状態にはできない(単一選択)
- `isProse`の場合、`prompt`中の`<u>`タグをそのまま活かしつつ、各下線部を選択肢と同じ「タップで反転・解除」要素にする(出現順を選択肢1〜nとみなす)
- カード最下部に出典(`examRef`、値がある場合のみ)
- 選択肢(または下線部)を選択した時点で、そのカードの★カウンターを+1し、選択中の内容を保持したまま裏へ反転できる

**回答(裏)カード**
- ヘッダー(表と同じ)
- 「正解：{answer}」
- `explanation`を整形表示。各選択肢解説の間に1行分の空白を空ける。各解説の冒頭にある判定文言(「適切である」「適切でない」「誤りである」「正しい」「最も適切である」「最も適切でない」等、末尾が「…である。」「…でない。」の判定表現)を、元データの太字有無によらず強制的に太字にする
- 表側で選択した選択肢と`answerIndex`を比較し、正解/不正解をこのカードのセッション記録に反映する

**操作**
- 「できた」「苦手」ボタン: 選択中と同じボタンを再度押すと状態解除(localStorage該当キー削除)
- ★カウンター: カードごとに0〜10個の★を最下部に表示。選択肢(または下線部)を選択するたびに+1(上限10)。カードごとの専用リセットボタンでそのカードの★のみ0に戻す。localStorage永続化、他の操作(できた/苦手・成績)では連動リセットしない
- 成績: 章を開始(`startChapter`)するたびにセッション記録をリセット。カードの表裏を反転させ選択済みの回答がある場合、正誤をそのセッション内に記録(カードID・正誤)。ツールバーに「成績を見る」ボタンを追加し、タップすると「◯問中◯問正解」+ 各問題番号ごとの正誤一覧をオーバーレイ表示する。セッションはlocalStorageに保存しない(リロード・章再開始でリセット)

## スコープ外

- 下線部問題以外の「注記付き」「複数行選択肢」問題(2章10問・12章15問など)の完全構造化(地の文フォールバックで対応)
- 難易度表示
- 成績の永続化・端末間同期
